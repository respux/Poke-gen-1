# Poke Gen 1

Leer-app voor kleine kinderen: alle 1025 Pokémon (generatie 1 t/m 9), in volgorde of door elkaar.

- Naam voorlezen (Engelse stem) en kreet afspelen
- Instellingen: filter per generatie en type (meerdere tegelijk, standaard generatie 1), volgorde, taal, automatisch voorlezen met wachttijd
- Zoeken op naam of nummer via het 🔍-icoon
- Types en aanvallen in het Nederlands of Engels
- Eén zelfstandig bestand: `index.html` (afbeeldingen en geluiden zijn ingebed), werkt ook offline

## Gebruik
Open `index.html` in een browser, of zet GitHub Pages aan (Settings → Pages → branch `main`, map `/root`).

## Bronnen
Gegevens (namen, types, generaties) uit [PokeAPI](https://github.com/PokeAPI/pokeapi). Sprites en kreten uit [PokeAPI/sprites](https://github.com/PokeAPI/sprites) en [PokeAPI/cries](https://github.com/PokeAPI/cries).
Pokémon is een merk van Nintendo, Game Freak en The Pokémon Company; dit is een privé-leerproject zonder commercieel doel.

## Opmerkingen
- De Nederlandse aanvalsnamen zijn eigen vertalingen, niet de officiële namen.
- Aanvallen van generatie 2 t/m 9 zijn automatisch gekozen (passend bij type en leerbaar), niet per se de kenmerkende aanvallen.
